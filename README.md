# PuzzleSmith

A chess processing pipeline built in Go for analyzing users' games with Stockfish and generating puzzles from the analysis.

## Project structure

- `apps/api` — Go backend using Chi and the standard library's `net/http`, with Stockfish integration and PostgreSQL queries generated by sqlc.
- `apps/web` — React and TypeScript frontend built with Vite, using pnpm.

## Local development

Use the Go version declared in `apps/api/go.mod`, Node.js 24, and pnpm 10. Backend runtime setup also requires PostgreSQL, Stockfish, and the application's local environment configuration.

Backend:

```sh
cd apps/api
go mod download
go run .
```

Frontend, in a separate terminal:

```sh
cd apps/web
pnpm install --frozen-lockfile
pnpm dev
```

Keep local credentials in ignored `.env` files. Example environment files can be committed without secrets.

## CI

The GitHub Actions workflow in `.github/workflows/ci.yml` runs on pushes and pull requests targeting `main`:

- **Frontend:** install dependencies from the lockfile and build.
- **Backend:** download dependencies, vet all packages, and build the Chi/net/http server to `apps/api/bin/api`.

Deployment is not configured in this repository.
